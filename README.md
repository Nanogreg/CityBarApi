# CityBarApi

`CityBarApi` est une API Web REST développée en **.NET** qui fournit des données pour une application cliente (application mobile ou web). Elle permet de gérer et de récupérer des informations concernant les villes, les bars, les promotions et les événements.

## 🚀 Fonctionnalités Actuelles

L'API expose des points de terminaison (endpoints) pour récupérer les ressources suivantes :
- 🏙️ **Villes (Cities)** : Liste des villes.
- 🍻 **Bars** : Informations sur les bars partenaires ou enregistrés.
- 🏷️ **Promotions (Promo)** : Offres spéciales et réductions en cours.
- 📅 **Événements (Event)** : Soirées, concerts ou événements prévus dans les bars.

## 🔒 Sécurité

* **Aucune authentification (No auth)** n'est requise pour le moment. L'ensemble des endpoints est accessible publiquement.

## 🛠️ Technologies

- **Framework :** .NET
- **Architecture :** REST API
